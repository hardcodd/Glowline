# Подготовка распространения

[English](DISTRIBUTION.md)

Сценарии сборки и упаковки готовят файлы без автоматической публикации релиза GitHub или отправки в Apple. Версия 1.0.0 распространяется с подписью ad-hoc и инструкцией разрешения запуска отдельного приложения через Gatekeeper. Подпись Developer ID и нотарификация рекомендуются для упрощения установки; в этом релизе их нет.

1. Проект распространяется по [лицензии MIT](../LICENSE). Перед распространением подтвердите права на исходники и ресурсы. Неиспользуемый заголовок API плагинов Skydimo больше не включается. Системные фреймворки предоставляет macOS; сторонние библиотеки выполнения в приложение не включены. Удаление заголовка не заменяет юридическую проверку происхождения каждого исторического файла.
2. Просмотрите изменения, увеличьте build в `VERSION.json` при изменении бинарного файла и соберите на Apple Silicon с доступной минимальной поддерживаемой macOS. Bundle identifier остаётся `local.alex.Glowline`, сохраняя установленную identity. Локальные самопроверки используют временные папки настроек, не открывают USB и не регистрируют автозапуск.
3. Выполните `rtk proxy python3 build.py`. Для Developer ID передайте `--sign-identity` с доступным сертификатом Developer ID Application. Сначала подписывается движок, затем приложение; для подписи, отличной от ad-hoc, включаются hardened runtime и отметка времени. Нужны действующий сертификат и закрытый ключ; не включайте учётные данные в исходники и журналы.
4. Выполните `rtk proxy python3 package.py`. Проверяются распаковка ZIP, подписи и целостность DMG. `--verify-mount` дополнительно сверяет содержимое образа, подключённого только для чтения, если macOS разрешает подключение. Итоговые хеши находятся в `build/distribution/SHA256SUMS`; `manifest.json` содержит хеши файлов внутри пакета. Живые настройки, журналы, экспорты, резервные копии и рабочая папка исходников не включаются.
5. При наличии разрешения и настроенных локально учётных данных выполните [нотарификацию по инструкции Apple](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution). Отправьте пакет Developer ID через `notarytool`, проверьте результат, прикрепите ticket, проверьте его и пересчитайте хеши. Скрипты этого не делают. Пакет ad-hoc предназначен только для локальной проверки и может отклоняться Gatekeeper.
6. Проверьте итоговую скачанную сборку на чистом Mac или в чистой учётной записи: установку, выдачу/отказ доступа к экрану и повторный запуск, выбор USB, все режимы, выключение, профили, обновление с сохранением данных, переподключение, сон/пробуждение, вход после перезагрузки и удаление. До расширения заявлений о совместимости проверьте macOS 15 и второй совместимый контроллер. Записывайте только выполненные проверки; оптическая калибровка проверяется отдельно.

`.github/workflows/check.yml` готовит CI с правами только на чтение для Apple Silicon macOS 15/26: сборка, автономные тесты, санитайзеры и упаковка ZIP. Нет создания релиза, загрузки артефактов, секретов подписи или нотарификации. Текущие результаты доступны в [GitHub Actions](https://github.com/hardcodd/Glowline/actions). Успешный запуск подтверждает сборку и автономные проверки на соответствующей системе, но не физическое устройство или интерактивную установку.
