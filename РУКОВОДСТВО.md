# Glowline — подсветка монитора для macOS и Skydimo SK0L34

Glowline — нативное приложение macOS в строке меню, которое синхронизирует **USB-подсветку монитора Skydimo SK0L34 на 112 светодиодов** с краями изображения на экране. В интерфейсе SwiftUI доступны шесть режимов, тёплый фоновый свет, коррекция отдельных сторон и локальные профили.

[Скачать для Apple Silicon](https://github.com/hardcodd/Glowline/releases/latest) · [English guide](README.md) · [Установка и обновление](docs/INSTALL.ru.md) · [Сообщить об ошибке](https://github.com/hardcodd/Glowline/issues)

![Glowline для macOS: подсветка Skydimo SK0L34 на 112 светодиодов по изображению экрана, регулировка яркости и теплоты](docs/images/glowline-macos-ambient-lighting.png)

*Скриншот работающего приложения с русским интерфейсом. Контур монитора показывает отправляемые цвета, а не измеренное свечение. В версии 1.0.0 немного изменены поясняющие тексты.*

**Версия 1.0.0, сборка 2:** Apple Silicon, macOS 15+. Пакет подписан ad-hoc, без платного сертификата Developer ID и нотарификации Apple. При первом запуске может потребоваться вручную разрешить открытие в настройках macOS — порядок ниже.

## Подходящая лента

**Нужен контроллер Skydimo SK0L34 с фиксированной схемой подсветки монитора на 112 светодиодов.** Одного названия Skydimo, похожего разъёма или совпадения числа светодиодов недостаточно для подтверждения совместимости.

| Требование | Поддерживаемая конфигурация |
| --- | --- |
| Компьютер | Mac с Apple Silicon; Intel Mac не поддерживается |
| Операционная система | macOS 15 или новее; границы проверки указаны ниже |
| Контроллер и лента | Skydimo SK0L34, 112 LED, существующая фиксированная схема по периметру |
| USB-протокол | Последовательное соединение 115200 бод; RGB-кадры по 342 байта |
| Ответ устройства | На запрос `Moni-A` возвращается `SK0L34,` и семь байтов устройства, с необязательным завершением CR LF |
| Синхронизация с экраном | Разрешение macOS «Запись экрана» |
| Интерфейс | Русский |

**Привязки к серийному номеру автора нет.** Совместимые контроллеры могут возвращать другие байты устройства. До передачи цветов Glowline проверяет ответ модели, но он не сообщает количество или расположение светодиодов. Соответствие схеме на 112 LED нужно проверить самостоятельно. Иная длина или модель, универсальные RGB-ленты, Bluetooth/Wi-Fi-контроллеры и Windows/Linux не поддерживаются. Прошивка не меняется.

Проверена одна физическая конфигурация SK0L34. Второй физический контроллер не тестировался; имитация разных идентификаторов в тестах не гарантирует аппаратную совместимость.

## Установка и первый запуск

Для готового приложения не нужны Python, RTK, Xcode или платная учётная запись разработчика Apple.

1. Скачайте **ZIP или DMG для arm64** и `SHA256SUMS` со страницы [GitHub Releases](https://github.com/hardcodd/Glowline/releases/latest). Достаточно одного формата: приложение одинаковое.
2. Распакуйте ZIP или откройте DMG. Скопируйте `Glowline.app` в `~/Applications/` и запускайте оттуда. При необходимости создайте папку.
3. Если macOS блокирует приложение из-за непроверенного разработчика или отсутствия проверки Apple, закройте предупреждение. Откройте **Системные настройки → Конфиденциальность и безопасность**, найдите сообщение о Glowline и нажмите **«Всё равно открыть»**, затем подтвердите открытие. Делайте это только для официальной загрузки, которой доверяете. Обычно macOS сохраняет исключение для этой копии. [Инструкция Apple](https://support.apple.com/en-us/102445).
4. Завершите Skydimo и другие программы управления лентой. В разделе **Приложение** выберите свой последовательный USB-порт. В новой установке порт не выбран.
5. Для режима **Экран** разрешите Glowline **запись экрана** в настройках конфиденциальности macOS. При запросе завершите и снова откройте приложение. Пять остальных режимов работают без доступа к экрану.
6. Проверьте статус автозапуска в разделе **Приложение**. По умолчанию включены запуск при входе и скрытый старт; macOS может запросить разрешение в объектах входа.

Не отключайте Gatekeeper целиком. Сообщение «приложение повреждено» или «повредит компьютер» требует отдельной проверки: это не обычный запрос о неизвестном разработчике. На управляемом Mac исключения могут быть запрещены. Первый запуск скачанного пакета на чистом Mac ещё не проверен.

Закрытие окна оставляет подсветку и приложение в строке меню. Открыть настройки можно через значок Glowline; полный выход — через меню или **Command-Q**. Из меню также доступны выключатель света, режимы и сохранённые профили.

Проверка контрольной суммы, обновление, восстановление разрешений и удаление описаны в [инструкции установки](docs/INSTALL.ru.md).

## Режимы

| Режим | Поведение |
| --- | --- |
| Экран | Передаёт на ленту цвета соответствующих краёв экрана |
| Один цвет | Ровный настраиваемый цвет по всей ленте |
| Градиент | Распределение двух цветов вдоль ленты |
| Дыхание | Анимированное изменение яркости |
| Радуга | Движущийся многоцветный эффект |
| Свеча | Тёплое анимированное свечение |

Общий выключатель отправляет чёрный цвет, сохраняя настройки. Цвета, скорость и направление эффектов регулируются там, где применимо.

## Настройки

| Раздел | Управление |
| --- | --- |
| Освещение | Предпросмотр передаваемых цветов, яркость, теплота и быстрый выбор режима |
| Цвет и теплота | Яркость, теплота, насыщенность, гамма, усиление RGB и порог чёрного |
| Захват экрана | Дисплей, взвешенная глубина от края, нарастание/затухание, зеркалирование, смещение LED, включение и усиление сторон, частота захвата и ограничение передачи |
| Режимы и эффекты | Режим, цвета эффектов, скорость и направление |
| Мои профили | Именованные профили, импорт/экспорт JSON и сброс к исходным значениям |
| Приложение | USB-порт, переподключение, автозапуск, скрытый старт, выключение при выходе, оформление, разрешения и журнал |

Изменения применяются автоматически. Исходные значения: яркость **100%**, теплота **50%**, зеркалирование включено, глубина **15%**, постоянная времени затухания **180 мс**, мгновенное нарастание, захват **120 Гц**, предел передачи **33,68 FPS**, повтор статичного цвета **100 мс**. Теплота увеличивается до **90%**; это художественная коррекция, а не калиброванная температура в кельвинах.

Частота захвата и частота вывода на LED различаются. Пропускная способность последовательного соединения ограничена: 120 Гц захвата не означают 120 FPS на ленте. Подавление одинаковых кадров уменьшает лишние записи. Прежний тест движущегося изображения на одной конфигурации дал около 26,6 FPS передачи; это не гарантированная частота или измерение задержки.

При ошибке захвата прежние цвета экрана очищаются, приложение показывает ошибку. При включённых переподключении и свете выполняются до трёх перезапусков с увеличением интервалов; десять секунд нормальной работы восстанавливают лимит. Если ошибка остаётся, проверьте доступ к экрану и нажмите **Переподключить**.

## Профили, обновления и приватность

Настройки, профили и диагностические файлы ограниченного размера сохраняются локально в `~/Library/Application Support/Glowline/`, отдельно от приложения. Снимки экрана и звук не сохраняются и никуда не отправляются. Учётная запись или облачный сервис Glowline не нужны.

Перед обновлением экспортируйте JSON из **Мои профили**. Завершите приложение, замените его по прежнему пути и сохраните старую копию до проверки. Настройки и профили сохраняются; отсутствующие поля прежних версий получают исходные значения. Некорректные данные и неподдерживаемые схемы отклоняются; нечитаемые при запуске настройки сохраняются в резервной копии. Изменение подписи может потребовать повторного разрешения записи экрана.

Сброс настроек подсветки сохраняет выбранный USB-порт и именованные профили. Импортированный профиль может содержать порт другого Mac: выберите свой заново. См. [обновление и удаление](docs/INSTALL.ru.md).

## Решение проблем

| Симптом | Действие |
| --- | --- |
| macOS блокирует первый запуск | Разрешите открытие только Glowline по инструкции выше; не выключайте защиту системы |
| Нет цветов экрана | Разрешите запись экрана установленной копии и откройте её заново; после смены подписи при необходимости удалите только Glowline из списка разрешений и добавьте установленную копию |
| Контроллер недоступен или занят | Завершите другие программы подсветки, проверьте USB и выберите правильный порт |
| Ответ устройства отклонён | Проверьте протокол SK0L34 и ленту на 112 LED; другие модели и некорректные ответы отклоняются |
| Мерцание через USB-хаб | Проверьте питание ленты и внешнее питание хаба |
| Цвета попадают на другую сторону | Проверьте зеркалирование, смещение LED и стороны; иная физическая схема автоматически не определяется |
| После закрытия окна приложение работает | Это поведение приложения в строке меню; для выхода используйте меню или Command-Q |
| Автозапуск требует согласия | Проверьте статус регистрации и объекты входа macOS |

В [сообщении об ошибке](https://github.com/hardcodd/Glowline/issues) укажите версию macOS, архитектуру Mac, модель контроллера, число LED и шаги воспроизведения. Просмотрите журнал и экспорт профиля перед публикацией: там могут быть локальные пути или идентификатор USB-порта.

## Сборка из исходников

Нужны Apple Silicon, Apple Command Line Tools, Python 3 и [RTK](https://github.com/rtk-ai/rtk). Из папки исходников:

```sh
rtk proxy python3 build.py
rtk proxy open ./Glowline.app
```

Сборщик компилирует приложение SwiftUI/AppKit и движок ScreenCaptureKit/USB на Objective-C, запускает проверки C/Swift и проверяет подпись ad-hoc. Сторонних библиотек выполнения в пакете нет. После сборки может потребоваться повторное разрешение записи экрана.

```sh
rtk proxy python3 package.py
```

Упаковка создаёт ZIP, DMG и `SHA256SUMS` в `build/distribution/`: приложение, обе инструкции установки, MIT и манифест хешей файлов. Проверяются распаковка ZIP, извлечённые подписи и целостность DMG. `--skip-dmg` создаёт только ZIP; `--verify-mount` дополнительно проверяет содержимое подключённого образа, если macOS разрешает подключение. Сценарий ничего не публикует и не отправляет в Apple.

Подготовка подписи Developer ID и нотарификации описана в [документации распространения](docs/DISTRIBUTION.ru.md). Версия и сборка — в `VERSION.json`, код — в `Source/`, ресурсы — в `Resources/`, дополнительные тесты — в `Tests/`.

## Границы проверки

Локальные автоматические проверки покрывают цвет и управление, фрагментированные и неверные ответы контроллера, миграцию настроек, профили, очистку цветов при сбое захвата и ограниченное восстановление. C-проверки также запускались с AddressSanitizer и UndefinedBehaviorSanitizer. Сценарий CI запускает сборку и автономные проверки на macOS 15/26; он не проверяет физическую ленту или диалоги разрешений экрана.

Ранее на одном установленном экземпляре проверены шесть режимов, яркость, выключение света, профили, захват экрана и рост счётчиков переданных кадров. Новые пути восстановления кандидата релиза покрыты автоматическими проверками. Не проверены установка на чистом Mac, второй физический контроллер, сон/пробуждение и вход после перезагрузки. Локальная целостность DMG проверена, установка из подключённого образа — нет. Оптическая калибровка и измерение задержки от изображения до света не заявляются.
