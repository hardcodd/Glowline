Проверка света

Чистый чёрный фон и свет без формата 16:9. Подходит для широкого монитора. Панель скрывается на время теста.

H — панель · F — весь экран · Пробел — пауза · 1–6 — сцена · ← → — сдвиг · Esc — выход. В «Точности» щёлкните по фону, чтобы поставить пятно. Размер и отступ — доли короткой стороны экрана.

Для сравнения порога 0% / 3% используйте «Точность», затем добавьте ореол. Панель сама влияет на ленту — скройте её перед оценкой. Это визуальный тест, не измерение цвета.

Панель: H · пауза: пробел · выход: Esc
