# Glowline 1.1.0

[English](RELEASE-1.1.0.md)

Ежедневное расписание яркости и более чёткое разделение цветов — с сохранением текущих настроек и профилей.

## Новое

- **Расписание:** вручную задайте начало дня и ночи и яркость каждого периода. Работает по местному времени Mac во всех режимах; изначально выключено. Отключение возвращает ручную яркость. Расписание сохраняется в профиле.
- **Детализация цвета:** переключатель в «Захвате экрана» помогает меньше смешивать разные оттенки внутри зоны. Можно сразу сравнить с исходным усреднением; по умолчанию выключен. Число LED и насыщенность не меняются.
- **Целые шаги ползунков:** проценты по 1%, время по 1 мс, гамма по 0,01, скорость по 0,1×. Ранее сохранённые значения сохраняются точно до редактирования.
- **Тест подсветки:** автономный HTML с шестью сценами, паузой и полным экраном для любого формата монитора. Файл `lighting-test.html` включён в пакет.

## Исправления

- Переключение с тёмного оформления на системное и читаемость подписей в светлой теме.
- Разбор статуса движка, из-за которого возникали ложные переподключения и пропадал цветной предпросмотр.
- Русский краткий README по умолчанию и обновлённые подробные инструкции; английская версия доступна отдельно.

## Установка и обновление

Apple Silicon, macOS 15+, Skydimo SK0L34 с фиксированной схемой на 112 LED. Сборка 3. Скачайте ZIP или DMG — приложение в них одинаковое. `SHA256SUMS` содержит контрольные суммы.

Полностью завершите Glowline, замените приложение по прежнему пути. Настройки сохраняются автоматически отдельно от приложения; профиль — отдельный снимок, который нужно сохранять заново после подстройки. Экспорт JSON перед обновлением остаётся удобной резервной копией.

Подпись ad-hoc, без Developer ID и нотарификации Apple. При первом запуске может потребоваться «Всё равно открыть», после обновления — повторное разрешение записи экрана. Порядок описан в `INSTALL.ru.md` внутри пакета и [инструкции установки](https://github.com/hardcodd/Glowline/blob/main/docs/INSTALL.ru.md).

Автоматические проверки охватывают расписание, настройки/профили, шаги ползунков, оформление, выборку цвета, захват и протокол контроллера; проверяются подписи и целостность пакетов. Установка скачанного пакета на чистом Mac, второй физический контроллер и оптическая калибровка не проверены.
