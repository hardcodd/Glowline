# Установка, обновление и удаление Glowline

[English](INSTALL.md)

Нужны Apple Silicon, macOS 15 или новее и совместимая лента SK0L34 на 112 светодиодов. Интерфейс русский. Для запуска готового приложения Python, RTK и инструменты разработчика не нужны.


Текущие настройки сохраняются автоматически после изменений и восстанавливаются при запуске. Именованный профиль — отдельный снимок: сохраните его заново, чтобы обновить. Новые функции «Расписание» и «Детализация цвета» исходно выключены; включаются в соответствующих разделах. Для проверки скачайте и откройте включённый в пакет `lighting-test.html` в браузере: `F` — весь экран, пробел — пауза, `H` — панель.

## Установка

1. Сверьте скачанный файл с `SHA256SUMS` из того же доверенного источника.
2. Распакуйте ZIP или откройте DMG. Скопируйте `Glowline.app` в `~/Applications/` (при необходимости создайте папку). Запускайте приложение из этого постоянного места.
3. Завершите Skydimo и другие контроллеры. В разделе **Приложение** выберите USB-порт ленты.
4. Для режима «Экран» разрешите запись экрана в разделе конфиденциальности macOS. При запросе завершите и снова откройте Glowline. Остальные режимы работают без этого доступа.
5. Проверьте фактический статус автозапуска в разделе **Приложение**; macOS может потребовать подтверждение в объектах входа.

## Первый запуск без сертификата Apple Developer ID

Версия 1.3.0 подписана ad-hoc и не нотарифицирована Apple. Если macOS блокирует запуск из-за невозможности проверить разработчика или приложение:

1. Один раз попробуйте открыть установленную копию Glowline и закройте предупреждение.
2. Откройте **Системные настройки → Конфиденциальность и безопасность**, найдите сообщение о Glowline и нажмите **«Всё равно открыть»**.
3. Подтвердите **«Открыть»**, при запросе пройдите аутентификацию. Обычно macOS сохраняет исключение для этой копии.

Делайте это только для официальной загрузки GitHub, которой доверяете. [Порядок описан Apple](https://support.apple.com/en-us/102445). Не отключайте Gatekeeper целиком и не считайте предупреждение о повреждении или вредоносном ПО обычным запросом. Управляемый Mac может запрещать исключения. Первый запуск скачанного пакета на чистом Mac пока не проверен.

Для проверки ZIP выполните во встроенном Терминале и сравните результат со строкой этого файла в `SHA256SUMS`:

```sh
shasum -a 256 Glowline-1.3.0-build5-arm64.zip
```

Для DMG подставьте его имя. Совпадение хеша позволяет обнаружить изменение загрузки, но не заменяет сертификат Developer ID или нотарификацию.

## Обновление и восстановление

Экспортируйте настройки в разделе **Мои профили**. Полностью завершите Glowline и замените приложение по прежнему пути. Старую копию сохраните до проверки новой. Настройки и профили находятся в `~/Library/Application Support/Glowline/`, отдельно от приложения. Отсутствующие поля прежних настроек получают исходные значения; неподдерживаемые схемы и неверные типы отклоняются, а нечитаемый при запуске файл сохраняется в резервной копии.

Другая подпись может потребовать повторного доступа к экрану. Если переключатель включён, но захват не работает, удалите только Glowline из списка разрешений, добавьте установленную копию и откройте её заново. Проверьте USB-порт и статус автозапуска. Для возврата к прежней сборке завершите Glowline и восстановите сохранённое приложение. Не запускайте две копии или другой контроллер ленты одновременно.

После ошибки захвата прежние цвета экрана очищаются. При включённом переподключении и свете выполняются до трёх перезапусков с увеличением интервалов; десять секунд нормальной работы восстанавливают лимит. Если ошибка остаётся, проверьте разрешение и нажмите **Переподключить**. Изображение и звук не сохраняются и никуда не отправляются.

## Удаление

Выключите **Запускать при входе в macOS**, проверьте статус регистрации и завершите Glowline. Удалите приложение. Настройки останутся для повторной установки. Для полного удаления сначала экспортируйте нужные данные, затем удалите только `~/Library/Application Support/Glowline/`. При желании удалите запись Glowline из разрешений записи экрана macOS. Не удаляйте другие приложения или их разрешения.
