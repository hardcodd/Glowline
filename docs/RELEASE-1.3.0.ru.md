# Glowline 1.3.0

[English](RELEASE-1.3.0.md)

Glowline сосредоточен на подсветке экрана и декоративных эффектах ленты. Ночник Noctiluca вынесен в самостоятельный проект Dream Away и больше не входит в Glowline.

## Изменения

- Удалены встроенный ночник, его пункты меню, запуск по бездействию и ресурсы Metal. Настройки ленты, профили, расписание и девять режимов подсветки сохранены.
- Добавлен экспериментальный ранний отклик экрана с сохранением выборки по краям. По умолчанию он выключен; перед постоянным использованием сравните его с обычным захватом на своём оборудовании.
- Объединены проверки идентификации контроллера и декодирования half-float, добавлены автономные проверки и исправления совместимости сборки.
- Доступны исходники и CI для Windows 11 x64; этот релиз содержит только пакеты macOS. Работа Windows с физическим оборудованием пока не проверена.

## Установка и обновление

Apple Silicon, macOS 15+, Skydimo SK0L34 с фиксированной схемой на 112 LED. Сборка 5. ZIP и DMG содержат одинаковое приложение; сверьте их с `SHA256SUMS`.

Полностью завершите Glowline и замените приложение в прежнем месте. Сначала экспортируйте настройки для резервной копии. Настройки и профили хранятся вне приложения и сохраняются. Не запускайте несколько программ управления лентой одновременно. Прежние настройки ночника больше не используются и не настраивают Dream Away.

Подпись ad-hoc, без Developer ID и нотарификации Apple. Может потребоваться повторное разрешение записи экрана. См. [инструкцию установки](https://github.com/hardcodd/Glowline/blob/v1.3.0/docs/INSTALL.ru.md).

## Проверки и ограничения

Проверки релиза охватывают сборки, автономные контракты настроек, профилей, расписания и интерфейса, захват экрана и контроллер, подписи, контрольные суммы распакованного ZIP и содержимое DMG, подключённого только для чтения. Они не заменяют проверку физического оборудования и установки через интерфейс.

Пока не проверены установка скачанного пакета на чистом Mac, второй физический контроллер, вход после перезагрузки и оптическая калибровка.
