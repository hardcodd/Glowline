# Glowline 1.0.0

Нативная подсветка монитора для macOS и **USB-лент Skydimo SK0L34 на 112 светодиодов**. Первый публичный релиз готового приложения, сборка 2.

[English release notes](RELEASE-1.0.0.md) · [Полное руководство и скриншот](../РУКОВОДСТВО.md)

## Требования и совместимость

- Apple Silicon (arm64), macOS 15 или новее. Интерфейс русский.
- Skydimo SK0L34 с фиксированной схемой на 112 LED, последовательным протоколом 115200 бод и RGB-кадрами по 342 байта.
- Привязки к серийному номеру автора нет. Контроллер должен возвращать ожидаемый ответ модели SK0L34; число и расположение LED в ответе не передаются.
- Другая длина или модель ленты, Intel Mac и Bluetooth/Wi-Fi-контроллеры не поддерживаются. Второй физический контроллер не тестировался.

## Возможности

- Синхронизация с экраном через ScreenCaptureKit; один цвет, градиент, дыхание, радуга и свеча.
- Яркость, теплота до 90%, насыщенность, гамма, коррекция RGB и отдельных сторон.
- Глубина от края, нарастание/затухание, зеркалирование, смещение LED, выбор монитора и ограничение частоты передачи.
- Управление из строки меню, необязательные автозапуск и скрытый старт, именованные профили и импорт/экспорт JSON.
- Локальная обработка без сохранения/отправки снимков экрана, учётных записей или облачного сервиса.

## Исправления надёжности

- Поддерживаются ответы SK0L34 без завершения и с CR LF, включая передачу по частям; неверные и запоздавшие окончания отклоняются до передачи LED-кадров.
- Отсутствующие поля старых настроек и профилей получают исходные значения без потери сохранённых параметров.
- При сбое захвата прежние цвета очищаются, статус показывает ошибку. Автовосстановление ограничено тремя перезапусками с увеличением интервалов.
- Начальная частота захвата сохраняется при асинхронном запуске.

## Загрузка и первый запуск

Скачайте **один** пакет: ZIP или DMG. В обоих одинаковое приложение, инструкции установки на двух языках, MIT и манифест хешей файлов. `SHA256SUMS` содержит хеши обеих загрузок. Инструменты разработчика для запуска не нужны. Автоматические архивы GitHub «Source code» содержат исходники, а не готовое приложение.

1. Скопируйте `Glowline.app` в `~/Applications/` и откройте.
2. **Платного сертификата Developer ID и нотарификации Apple нет.** Если macOS блокирует приложение из-за непроверенного разработчика, откройте **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**, затем подтвердите открытие Glowline. Используйте только доверенную официальную загрузку; не отключайте Gatekeeper целиком. [Инструкция Apple](https://support.apple.com/en-us/102445).
3. Завершите другие программы управления лентой и выберите USB-порт в разделе **Приложение**.
4. Разрешите **запись экрана** для синхронизации; при запросе откройте приложение заново. Остальные режимы этого доступа не требуют.

Для обновления экспортируйте профили, завершите Glowline и замените приложение по прежнему пути. Настройки остаются вне пакета. Изменение подписи может потребовать повторного доступа к экрану. [Установка, обновление и удаление](INSTALL.ru.md).

## Проверки и известные ограничения

Прошли локальная полная сборка, C/Swift-контракты, C AddressSanitizer/UndefinedBehaviorSanitizer, искусственный сбой захвата, распаковка ZIP с проверкой хешей и подписи, проверка целостности DMG. Прежние аппаратные проверки покрывают шесть режимов на одном установленном экземпляре с SK0L34; новые пути восстановления покрыты автоматическими тестами.

Не проверены первый запуск скачанного пакета на чистом Mac, второй физический контроллер, сон/пробуждение, вход после перезагрузки и установка из подключённого DMG. Управляемый Mac может запрещать исключения Gatekeeper. Оптическая калибровка, гарантированная частота FPS и измеренная сквозная задержка не заявляются.
