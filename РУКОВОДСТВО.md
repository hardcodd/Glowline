# Glowline — подсветка монитора для macOS и Skydimo SK0L34

Glowline — нативное приложение macOS в строке меню, которое синхронизирует **USB-подсветку монитора Skydimo SK0L34 на 112 светодиодов** с краями изображения на экране. В интерфейсе SwiftUI доступны девять режимов, тёплый фоновый свет, коррекция отдельных сторон и локальные профили.

[Скачать для Apple Silicon](https://github.com/hardcodd/Glowline/releases/latest) · [English guide](docs/USER-GUIDE.en.md) · [Установка и обновление](docs/INSTALL.ru.md) · [Сообщить об ошибке](https://github.com/hardcodd/Glowline/issues)

Руководство описывает Glowline 1.2.0: пламя, комету, северное сияние, отдельные настройки эффектов и встроенный ночник на Metal.

![Glowline для macOS: подсветка Skydimo SK0L34 на 112 светодиодов по изображению экрана, регулировка яркости и теплоты](docs/images/glowline-macos-ambient-lighting.png)

*Скриншот работающего приложения с русским интерфейсом. Контур монитора показывает отправляемые цвета, а не измеренное свечение. Текущий интерфейс включает раздел «Расписание» и девять режимов подсветки.*

**Версия 1.2.0, сборка 4:** Apple Silicon, macOS 15+. Пакет подписан ad-hoc, без платного сертификата Developer ID и нотарификации Apple. При первом запуске может потребоваться вручную разрешить открытие в настройках macOS — порядок ниже.

## Подходящая лента

**Нужен контроллер Skydimo SK0L34 с фиксированной схемой подсветки монитора на 112 светодиодов.** Одного названия Skydimo, похожего разъёма или совпадения числа светодиодов недостаточно для подтверждения совместимости.

| Требование | Поддерживаемая конфигурация |
| --- | --- |
| Компьютер | Mac с Apple Silicon; Intel Mac не поддерживается |
| Операционная система | macOS 15 или новее; границы проверки указаны ниже |
| Контроллер и лента | Skydimo SK0L34, 112 LED, существующая фиксированная схема по периметру |
| USB-протокол | Последовательное соединение 115200 бод; RGB-кадры по 342 байта |
| Ответ устройства | На запрос `Moni-A` возвращается `SK0L34,` и семь байтов устройства, с необязательным завершением CR LF |
| Синхронизация с экраном | Разрешение macOS «Запись экрана» |
| Интерфейс | Русский |

**Привязки к серийному номеру автора нет.** Совместимые контроллеры могут возвращать другие байты устройства. До передачи цветов Glowline проверяет ответ модели, но он не сообщает количество или расположение светодиодов. Соответствие схеме на 112 LED нужно проверить самостоятельно. Иная длина или модель, универсальные RGB-ленты, Bluetooth/Wi-Fi-контроллеры и Windows/Linux не поддерживаются. Прошивка не меняется.

Проверена одна физическая конфигурация SK0L34. Второй физический контроллер не тестировался; имитация разных идентификаторов в тестах не гарантирует аппаратную совместимость.

## Установка и первый запуск

Для готового приложения не нужны Python, RTK, Xcode или платная учётная запись разработчика Apple.

1. Скачайте **ZIP или DMG для arm64** и `SHA256SUMS` со страницы [GitHub Releases](https://github.com/hardcodd/Glowline/releases/latest). Достаточно одного формата: приложение одинаковое.
2. Распакуйте ZIP или откройте DMG. Скопируйте `Glowline.app` в `~/Applications/` и запускайте оттуда. При необходимости создайте папку.
3. Если macOS блокирует приложение из-за непроверенного разработчика или отсутствия проверки Apple, закройте предупреждение. Откройте **Системные настройки → Конфиденциальность и безопасность**, найдите сообщение о Glowline и нажмите **«Всё равно открыть»**, затем подтвердите открытие. Делайте это только для официальной загрузки, которой доверяете. Обычно macOS сохраняет исключение для этой копии. [Инструкция Apple](https://support.apple.com/en-us/102445).
4. Завершите Skydimo и другие программы управления лентой. В разделе **Приложение** выберите свой последовательный USB-порт. В новой установке порт не выбран.
5. Для режима **Экран** разрешите Glowline **запись экрана** в настройках конфиденциальности macOS. При запросе завершите и снова откройте приложение. Восемь остальных режимов работают без доступа к экрану.
6. Проверьте статус автозапуска в разделе **Приложение**. По умолчанию включены запуск при входе и скрытый старт; macOS может запросить разрешение в объектах входа.

Не отключайте Gatekeeper целиком. Сообщение «приложение повреждено» или «повредит компьютер» требует отдельной проверки: это не обычный запрос о неизвестном разработчике. На управляемом Mac исключения могут быть запрещены. Первый запуск скачанного пакета на чистом Mac ещё не проверен.

Закрытие окна оставляет подсветку и приложение в строке меню. Открыть настройки можно через значок Glowline; полный выход — через меню или **Command-Q**. Из меню также доступны выключатель света, режимы и сохранённые профили.

Проверка контрольной суммы, обновление, восстановление разрешений и удаление описаны в [инструкции установки](docs/INSTALL.ru.md).

## Режимы

| Режим | Поведение |
| --- | --- |
| Экран | Передаёт на ленту цвета соответствующих краёв экрана |
| Один цвет | Ровный настраиваемый цвет по всей ленте |
| Градиент | Распределение двух цветов вдоль ленты |
| Дыхание | Анимированное изменение яркости |
| Радуга | Движущийся многоцветный эффект |
| Свеча | Тёплое анимированное свечение |
| Пламя | Раскалённые угли и живые языки огня |
| Комета | Бегущий огонёк с затухающим цветным шлейфом |
| Северное сияние | Плавные переливы и наложение цветных волн |

Общий выключатель отправляет чёрный цвет, сохраняя настройки. Цвета, скорость и направление эффектов регулируются там, где применимо.

Комета использует два выбранных цвета для длинного затухающего шлейфа и светлое ядро. Северное сияние использует собственную палитру: изумрудный, бирюзовый, синий, фиолетовый и розовый; пламя — оттенки от углей до жёлтого огня. Пламя имеет отдельную вертикальную ориентацию, не меняющую карту экранного режима. Скорость регулируется для всех анимаций; обратное направление доступно у радуги, кометы и сияния. Новые режимы сохраняются в профилях; номера прежних режимов не менялись. Их вид на физической ленте требует отдельной оценки.

В разделе «Режимы и эффекты» под сеткой режимов показываются только настройки выбранного эффекта:

| Режим | Свои настройки |
| --- | --- |
| Экран | Детализация цвета и глубина захвата; те же значения, что в разделе захвата |
| Один цвет | Цвет и готовые оттенки |
| Градиент | Два цвета и положение центра перехода |
| Дыхание | Цвет, скорость и минимальное свечение между вдохами |
| Радуга | Скорость, направление и плотность спектра |
| Свеча | Скорость и сила мерцания |
| Пламя | Скорость и высота языков огня |
| Комета | Два цвета, скорость, направление и длина шлейфа |
| Северное сияние | Скорость, направление и доля розовых переливов |

Цвета, скорость, направление и художественные параметры каждого эффекта запоминаются независимо при переключении и после перезапуска. Профили и JSON-экспорт включают все наборы. Старые настройки и профили используют прежние цвета и скорость как исходные значения; открытие не перезаписывает другие режимы. Яркость, расписание, цветовая калибровка, сглаживание, раскладка и производительность остаются общими. Сохранённый профиль — снимок: после донастройки сохраните его заново.

## Встроенный ночник Noctiluca

В Glowline 1.2.0 для macOS ночник включён в само приложение. Откройте **Приложение → Запустить ночник** или одноимённый пункт меню Glowline. Отдельное приложение, браузер и интернет не требуются. Ночник отрисовывается локально на Metal; отдельная среда выполнения не устанавливается.

У малых тел компактное неровное каменистое ядро, раскалённый нос и асимметричная испаряющаяся оболочка. По мере роста размера они переходят в солнца с конвективной поверхностью и отдельными дугами плазмы над короной. Огненные звёзды падают независимо: малые быстрее; большинство движется спокойно, а часть центральных метеоров идёт по встречным диагоналям с углом до 34°. Крупные падают строго вертикально, не больше одной крупной со всем её следом. При столкновении меньшая звезда разрушается в точке контакта, выбрасывая искры, огненные осколки и облако. Большая сохраняет размер, скорость и траекторию; маленькая не может разрушить гиганта. Дым остаётся на пути звезды. У нижнего края многослойный взрыв выбрасывает угловатые раскалённые осколки, быстрые искры и газ с объёмным освещением, который рассеивается в пыль. Гигант продолжает спуск, пока его верхняя кромка не окажется в нижней трети экрана; затем широкий взрыв поднимается от нижнего края. Масштаб разлёта связан с радиусом. Для реакции подсветки выберите режим **Экран**; запуск ночника сам не меняет настройки ленты.

**Esc** закрывает ночник и возвращает окно Glowline. **F** переключает полный экран, **Пробел** ставит на паузу, **S** открывает настройки, **N** включает ночной пресет, **H** скрывает управление. В выборе сцен пока доступен «Звездопад»; пробные световые течения и автоматическое чередование удалены. Доступны три палитры, яркость 3–100%, скорость 0,2–1,3×, заполнение экрана или 21:9, редкие чёрные паузы и таймер 30/60/120 минут. Последние 20 секунд таймера — затухание, затем рендер останавливается. Пробел возобновляет свет. Настройки ночника сохраняются отдельно от профилей ленты; закрытие освобождает GPU-ресурсы и удержание дисплея, не завершает Glowline.

Отрисовка использует Metal, локальную геометрию солнц, HDR-композицию и ограниченный буфер GPU-частиц; дым восстанавливается из половинного линейного разрешения. На экранах от 120 Гц выбран половинный темп обновления (72 FPS на 144 Гц), на остальных — цель 60 FPS. Фактические FPS и GPU-время видны в окне. Это цель, а не гарантия для любого оборудования. «Показать гиганта» вручную запускает редкое событие для оценки; обычная частота гигантов от этого не меняется.

## Настройки

| Раздел | Управление |
| --- | --- |
| Освещение | Предпросмотр передаваемых цветов, яркость, теплота и быстрый выбор режима |
| Цвет и теплота | Яркость, теплота, насыщенность, гамма, усиление RGB и порог чёрного |
| Расписание | Начало дня и ночи, отдельная яркость каждого периода |
| Захват экрана | Дисплей, взвешенная глубина от края, нарастание/затухание, зеркалирование, смещение LED, включение и усиление сторон, частота захвата и ограничение передачи |
| Режимы и эффекты | Девять режимов и отдельная панель настройки выбранного эффекта |
| Мои профили | Именованные профили, импорт/экспорт JSON и сброс к исходным значениям |
| Приложение | Запуск встроенного ночника, USB-порт, переподключение, автозапуск, скрытый старт, выключение при выходе, оформление, разрешения и журнал |

Оформление можно выбрать вручную — тёмное или светлое — либо включить **Как в macOS**. Системный режим следует теме macOS после любого ручного выбора; в светлой теме яркий янтарный акцент сочетается с тёмными читаемыми надписями.

Состояние подключения обновляется и при перетаскивании ползунков. Уведомления не сдвигают прокручиваемые настройки; плашку подключения можно закрыть крестиком.

Изменения применяются и сохраняются автоматически, в том числе после полного выхода и повторного запуска. Именованные профили — отдельные снимки: чтобы обновить профиль, сохраните его заново. Исходные значения: яркость **100%**, теплота **50%**, зеркалирование включено, глубина **15%**, постоянная времени затухания **180 мс**, мгновенное нарастание, захват **120 Гц**, предел передачи **33,68 FPS**, повтор статичного цвета **100 мс**. Теплота увеличивается до **90%**; это художественная коррекция, а не калиброванная температура в кельвинах.

Ползунки изменяют проценты по 1%, время по 1 мс, гамму по 0,01, скорость эффектов по 0,1× и FPS по 1 с сохранением точного верхнего предела 33,68. Существующие сохранённые значения и профили не округляются, пока вы не двигаете соответствующий ползунок.

**Яркость по времени:** в разделе **Расписание** задайте начало дня и ночи и яркость каждого с шагом 1%. Например, 100% с 08:00 и 50% с 22:00; время меняйте вручную по сезону. Изначально расписание выключено. Оно действует во всех режимах, пока Glowline запущен, в том числе в строке меню. После сна, перевода часов или смены часового пояса выбирается текущий период по местному времени Mac. Отключение возвращает прежнюю ручную яркость; при одинаковом времени начала используется ручная яркость с пояснением. Главный выключатель света действует всегда. Текущая яркость видна на главном экране и странице расписания; ручные ползунки яркости недоступны при действующем расписании. Расписание входит в профили и JSON-экспорт; старые профили отключают его. После настройки заново сохраните нужный профиль.

**Детализация цвета** в разделе захвата переключает исходное усреднение в линейном свете на выбор ведущей группы оттенков внутри каждой зоны LED. По умолчанию выключена, в том числе для старых профилей. Сохраняется максимальный канал среднего цвета; насыщенность, теплота и границы зон не меняются, число светодиодов не увеличивается. При равном вкладе конкурирующих оттенков и преимущественно нейтральной сцене результат приближается к среднему. Смена оттенков может стать заметнее, а баланс цветов сцены — измениться. При глубине 0% оба варианта используют одну центральную точку. Сравнивайте переключением на остановленном кадре; выключение возвращает исходный метод. При сохранении профиля в него входит и этот выбор.

Частота захвата и частота вывода на LED различаются. Пропускная способность последовательного соединения ограничена: 120 Гц захвата не означают 120 FPS на ленте. Подавление одинаковых кадров уменьшает лишние записи. Прежний тест движущегося изображения на одной конфигурации дал около 26,6 FPS передачи; это не гарантированная частота или измерение задержки.

При ошибке захвата прежние цвета экрана очищаются, приложение показывает ошибку. При включённых переподключении и свете выполняются до трёх перезапусков с увеличением интервалов; десять секунд нормальной работы восстанавливают лимит. Если ошибка остаётся, проверьте доступ к экрану и нажмите **Переподключить**.

Для сравнения откройте [автономный тест подсветки](docs/lighting-test.html), скачав HTML и запустив его в браузере. Он подстраивается под любой монитор, включая широкий. `F` — весь экран, `H` — скрыть управление, пробел — пауза, `1`–`6` — сцены.

**Ранняя реакция** — экспериментальный переключатель в разделе захвата и панели режима «Экран». Добавляет слабый сигнал от ярких объектов на расстоянии до половины экрана от соответствующего края; влияние плавно ослабевает к центру. Границы зон вдоль края не расширяются. Свет от краёв не затемняется, однотонная заливка не усиливается; смешанные сцены могут стать ярче и изменить оттенок зоны. Порог чёрного и цветокоррекция продолжают действовать и могут скрывать слабый сигнал. Схема глубины показывает основную область захвата, без дополнительного сигнала. При глубине 0% эксперимент не действует. По умолчанию выключен, включая старые профили; переключение работает без перезапуска, выбор входит в сохранённый профиль. Это изменение алгоритма, а не увеличение числа физических LED или скорости контроллера.

## Профили, обновления и приватность

Настройки, профили и диагностические файлы ограниченного размера сохраняются локально в `~/Library/Application Support/Glowline/`, отдельно от приложения. Снимки экрана и звук не сохраняются и никуда не отправляются. Учётная запись или облачный сервис Glowline не нужны.

Перед обновлением экспортируйте JSON из **Мои профили**. Завершите приложение, замените его по прежнему пути и сохраните старую копию до проверки. Настройки и профили сохраняются; отсутствующие поля прежних версий получают исходные значения. Некорректные данные и неподдерживаемые схемы отклоняются; нечитаемые при запуске настройки сохраняются в резервной копии. Изменение подписи может потребовать повторного разрешения записи экрана.

Сброс настроек подсветки сохраняет выбранный USB-порт и именованные профили. Импортированный профиль может содержать порт другого Mac: выберите свой заново. См. [обновление и удаление](docs/INSTALL.ru.md).

| Симптом | Действие |
| --- | --- |
| macOS блокирует первый запуск | Разрешите открытие только Glowline по инструкции выше; не выключайте защиту системы |
| Нет цветов экрана | Разрешите запись экрана установленной копии и откройте её заново; после смены подписи при необходимости удалите только Glowline из списка разрешений и добавьте установленную копию |
| Контроллер недоступен или занят | Завершите другие программы подсветки, проверьте USB и выберите правильный порт |
| Ответ устройства отклонён | Проверьте протокол SK0L34 и ленту на 112 LED; другие модели и некорректные ответы отклоняются |
| Мерцание через USB-хаб | Проверьте питание ленты и внешнее питание хаба |
| Цвета попадают на другую сторону | Проверьте зеркалирование, смещение LED и стороны; иная физическая схема автоматически не определяется |
| После закрытия окна приложение работает | Это поведение приложения в строке меню; для выхода используйте меню или Command-Q |
| Автозапуск требует согласия | Проверьте статус регистрации и объекты входа macOS |

В [сообщении об ошибке](https://github.com/hardcodd/Glowline/issues) укажите версию macOS, архитектуру Mac, модель контроллера, число LED и шаги воспроизведения. Просмотрите журнал и экспорт профиля перед публикацией: там могут быть локальные пути или идентификатор USB-порта.

## Сборка из исходников

Нужны Apple Silicon, Apple Command Line Tools, Python 3 и [RTK](https://github.com/rtk-ai/rtk). Из папки исходников:

```sh
rtk proxy python3 build.py
rtk proxy open ./Glowline.app
```

Сборщик компилирует приложение SwiftUI/AppKit и движок ScreenCaptureKit/USB на Objective-C, запускает проверки C/Swift и проверяет подпись ad-hoc. Сторонних библиотек выполнения в пакете нет. После сборки может потребоваться повторное разрешение записи экрана.

```sh
rtk proxy python3 package.py
```

Упаковка создаёт ZIP, DMG и `SHA256SUMS` в `build/distribution/`: приложение, обе инструкции установки, MIT, автономный тест подсветки и манифест хешей файлов. Проверяются распаковка ZIP, извлечённые подписи и целостность DMG. `--skip-dmg` создаёт только ZIP; `--verify-mount` дополнительно проверяет содержимое подключённого образа, если macOS разрешает подключение. Сценарий ничего не публикует и не отправляет в Apple.

Подготовка подписи Developer ID и нотарификации описана в [документации распространения](docs/DISTRIBUTION.ru.md). Версия и сборка — в `VERSION.json`, код — в `Source/`, ресурсы — в `Resources/`, дополнительные тесты — в `Tests/`.

Ночник собирается из `Source/Ambient/` в тот же исполняемый файл Glowline; `Resources/Noctiluca.metal` входит в пакет. Для изолированной проверки интерфейса и GPU без второго контроллера ленты используйте `rtk python3 build.py --output-app /tmp/GlowlineReview.app --ambient-review`. Эта сборка имеет отдельное состояние и не меняет рабочие профили, разрешения или автозапуск. Обычный кандидат можно собрать с `--output-app /tmp/GlowlineCandidate.app`, затем упаковать через `rtk python3 package.py --app /tmp/GlowlineCandidate.app --output-dir /tmp/GlowlinePackages --skip-dmg`. GPU-прогон без запуска контроллера: `rtk /tmp/GlowlineCandidate.app/Contents/MacOS/Glowline --ambient-benchmark /tmp/GlowlineGPU`; он сохраняет PNG и JSON с GPU-временем, которое отличается от FPS окна.

## Границы проверки

Локальные автоматические проверки покрывают цвет и управление, фрагментированные и неверные ответы контроллера, миграцию настроек, профили, очистку цветов при сбое захвата и ограниченное восстановление. C-проверки также запускались с AddressSanitizer и UndefinedBehaviorSanitizer. Сценарий CI запускает сборку и автономные проверки на macOS 15/26; он не проверяет физическую ленту или диалоги разрешений экрана.

Ранее на одном установленном экземпляре проверены шесть режимов, яркость, выключение света, профили, захват экрана и рост счётчиков переданных кадров. Новые пути восстановления кандидата релиза покрыты автоматическими проверками. Не проверены установка на чистом Mac, второй физический контроллер, сон/пробуждение и вход после перезагрузки. Локальная целостность DMG проверена, установка из подключённого образа — нет. Оптическая калибровка и измерение задержки от изображения до света не заявляются.
